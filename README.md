# 0/1 Knapsack Metaheuristics (Java)

Semester project for solving the 0/1 Knapsack problem using metaheuristic search algorithms in Java.

## Project Structure

- `src/geneticalgorithm/` — Phase 1: Genetic Algorithm (population initialization, tournament selection, single-point crossover, mutation, and multi-generation loop).
- `src/proposedmetaheuristic/` — Phase 2: Placeholder for the custom metaheuristic algorithm to be added next.

## Phase 1: Genetic Algorithm

- **Classes:** `KnapsackGA.java`, `KnapsackProblem.java`, `Individual.java`, `Operations.java`, `CommonUtils.java`
- **How to run:** Compile the files under `src/geneticalgorithm/` and run `KnapsackGA`.
